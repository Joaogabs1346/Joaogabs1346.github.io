# João Gabriel de Souza Pinto, portfolio

Personal site of a Senior GenAI Software Engineer, live at https://joaogabs1346.github.io.

Plain HTML, CSS and JavaScript with no build step; GitHub Pages serves the repository directly.

- `index.html`: all content
- `assets/css/style.css`: styles (colors and spacing are CSS variables at the top)
- `assets/js/main.js`: hero text streaming, mobile menu, active nav link

To add a project, copy one `<li class="project">` block in the Projects section of `index.html`.
